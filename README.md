# FieldScout v0.9.0 — Static Stable

> **Taiwan Biodiversity Field Scouting Tool / 臺灣生物多樣性野外探點工具**

[繁體中文](README_ZH.md) | [English](README_EN.md)

FieldScout v0.9.0 is the **final pre-backend GitHub Pages edition**.

It adds local email profiles, IndexedDB, marker clustering, multi-source occurrence merging, advanced filtering, named trips, GPX workflows, automatic specimen numbering, batch collection-site mode, local photos, QC, backup/restore, seasonal summaries, and sensitive-coordinate export.

**Important:** entering an email is not authentication. The email is only a local profile key in the same browser/device. Cross-device synchronization will require a future backend.

See the full language-specific documentation above.
